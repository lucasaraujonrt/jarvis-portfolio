    Protótipo · óculos Meta, iPhone e o seu Mac

    Diga o nome.
    Seu Mac trabalha.

    Jarvis liga os óculos aos agentes de terminal do seu computador. Você fala, o agente executa, e você decide pelo iPhone.

    Pronto para ouvir

    Seu próximo pedido começa com a sua voz.

    Arraste os óculos para girar

    01 Ouvir

    Toque para falar. Ou ative pela voz.

    Com a sessão dos óculos ativa, Falar com Jarvis abre a conversa. A opção “Ativar ao dizer Jarvis” também inicia pela palavra de ativação. A voz Zagan usa a API da xAI.

    A rota de microfone e áudio dos óculos depende da sessão Bluetooth ativa e deve ser conferida no dispositivo.

    02 Delegar

    Fale o pedido inteiro, do jeito que sai. O Jarvis entende a intenção e envia para o agente escolhido, no projeto certo do seu Mac.

    03 Trabalhar

    O agente que você já usa. No seu Mac.

    Um gateway roda no seu Mac e envia a tarefa ao agente escolhido. O workspace é fixado ao iniciar o gateway; o CLI pode enviar contexto ao seu provedor.

    08 Começar
    
        
    Avalie o código. Depois reproduza a demo.
    
        
    Sem hardware ou serviços pagos, rode npm ci, npm test e npm run typecheck. O roteiro completo está em docs/SETUP.md.
    
        
    
          
    
            
    Configurar
    
            
      
              
    1. O que você precisaUm Mac acordado com Node 22.18 ou mais novo, um iPhone com iOS 17.2 ou mais novo, e óculos Meta pareados no app Meta AI, com Developer Mode ligado.
      2. 
              
    2. Agente no MacInstale e autentique o Codex para repetir a demo. Claude Code e Grok Code são opcionais.
      3. 
              
    3. Chave de vozCopie .env.example para .env e preencha XAI_API_KEY no Mac. A API de voz pode ter custo; os testes locais não usam essa chave.
      4. 
              
    4. GatewayGere um token com openssl rand -hex 24 e salve em JARVIS_GATEWAY_TOKEN no .env. Carregue o .env e suba o gateway no IP local, porta 4317, com --workspace em uma pasta descartável. Não exponha a porta à internet.
      5. 
              
    5. App no iPhoneAbra apps/ios/JarvisSpike.xcodeproj no Xcode; configure seu Team e bundle ID. Em Developer Mode, use META_APP_ID=0 e CLIENT_TOKEN vazio. Instale no iPhone e, em Conexões, use http://IP-do-Mac:4317, o mesmo token do .env e Codex.
      6. 
            
    
          
    
          
    
            
    Usar
    
            
      
              
    1. Conecte os óculosToque Conectar óculos, termine o registro no Meta AI e volte para Iniciar sessão.
      2. 
              
    2. FaleNa aba Jarvis, toque Falar com Jarvis e peça ao Codex para criar um arquivo. Dizer “Jarvis” antes é opcional quando a ativação por voz está ligada.
      3. 
              
    3. AproveSe o agente precisar de permissão, o iPhone mostra Permitir uma vez ou Recusar. Sem resposta em dois minutos, o pedido é recusado.
      4. 
              
    4. Confira o resultadoConfira o arquivo no Mac. Texto e andamento ficam na aba Tarefas; valide o áudio nos óculos separadamente.
      5.
